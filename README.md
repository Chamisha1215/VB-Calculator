# VB.NET Calculator

A simple Windows Forms Calculator application built with VB.NET and Visual Studio.

## Features
- Basic Operations: +, -, *, /, %
- AC - All Clear, Del - Delete Last Character
- Decimal point support
- Clean UI

## Screenshot
![Calculator UI](screenshot.png)

## How to Run
1. Clone this repository
2. Open `Calculator.slnx` in Visual Studio 2026
3. Press F5 to run

## Built With
- VB.NET
- .NET Framework
- Windows Forms
